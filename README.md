# Hands-On Data Lab Implementation

## Objective
Practice a reproducible workflow using Python, pandas and matplotlib: inspect data, clean it, calculate summaries, and create a chart.

## Windows setup
1. Install Python 3 from https://www.python.org/downloads/ if needed.
2. Open Command Prompt in this folder.
3. Run:
   ```bat
   python -m venv .venv
   .venv\Scripts\activate
   python -m pip install -r requirements.txt
   python analysis.py
   ```
4. Optional interactive notebook environment: run `jupyter notebook`.

## Dataset
`data/sales_data.csv` is a fictional practice dataset, not real business data.

## Files
- `analysis.py`: data cleaning, analysis, and visualisation.
- `data/sales_data.csv`: sample data.
- `requirements.txt`: dependencies.
- `report.docx`: submission report.
